introduction
This project focuses on analysing pizza sales data using MySQL to identify sales trends, customer ordering patterns, popular pizza categories and revenue performance.
The project uses a dataset containing 1000+ records to perform data exploration and business analysis through SQL queries

Project Objectives
Analyse total pizza sales and revenue.
Identify the best-selling and least-selling pizzas.
Understand customer ordering patterns.
Analyse monthly and daily sales trends.
Evaluate category-wise and size-wise sales performance.

 Tools & Technologies
MySQL
MySQL Workbench
SQL

Database Structure
The database consists of four tables:
Orders: Contains order ID, order date and order time.
Order Details: Contains order details, pizza ID and quantity.
Pizzas: Contains pizza ID, pizza size and price
Pizza Types: Contains pizza names, categories 

 Conclusion
This project demonstrates the application of SQL for real-world business data analysis. It showcases data exploration, data manipulation, joins, aggregation and advanced SQL techniques to extract meaningful insights from pizza sales data.
